# Campo AI

Sito web di presentazione del plugin ChatGPT per la gestione dell'azienda agricola.

Il codice del sito si trova nella cartella `front end/`.

## Avvio in locale

```sh
cd "front end"
npm install
npm run dev
```

## Struttura

- `front end/src` — pagine, componenti e contenuti del sito
- `front end/public` — file statici
- `front end/package.json` — dipendenze e comandi
